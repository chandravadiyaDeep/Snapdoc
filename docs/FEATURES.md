# Feature specification

## P0 core
- Home and local document library
- CameraX preview and capture
- Multi-page capture session
- Crop, rotate and reorder pages
- Original, grayscale and high-contrast presets
- Images-to-PDF with page size and margins
- Import PDFs/images via Storage Access Framework
- Merge and page-range split PDFs
- Local rename, delete, share and print

## P1
- Automatic edge detection and perspective correction
- Batch import/export
- PDF optimization with quality choices and measured output size
- Search, folders and favourites

## P2 commercial
- Pro unlock for batch workflows and advanced enhancement
- Optional ads outside capture/editing
- Play Billing and restore purchases

Never report compression success without measuring output bytes. Preserve source files.
