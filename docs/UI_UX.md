# UI/UX direction

Brand: Snapdoc — Scan. Organize. Export.

Visual: premium navy base, cool blue accent, readable typography, generous spacing and restrained motion. Main navigation: Home, Files, Settings. Scanner flow: camera preview → capture → review → crop/enhance → add pages → name → PDF export.

Use real empty states, accessible labels, clear permission recovery, loading/progress and confirmations for destructive actions. Support light and dark themes before public release.
