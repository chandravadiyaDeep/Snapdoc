# Snapdoc — Product Vision

Build a privacy-first Android document scanner and PDF toolkit that works without internet access. Target students, freelancers, small businesses and people digitizing paperwork.

## Principles
- Offline-first core workflows.
- No mandatory account or automatic cloud upload.
- Fast capture, review and export.
- Preserve originals; never overwrite without consent.
- Accessible controls and clear errors.

## V1 success
Capture multipage scans, crop and enhance pages, save local PDFs, import/merge/split PDFs, and complete core tasks in airplane mode.
